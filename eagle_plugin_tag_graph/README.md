# Eagle 标签蛛网图插件

这是一个独立的 Eagle 窗口插件，用来在 Eagle 内分析标签出现次数和标签共现关系。

当前开发版本：`0.3.3`

## 当前功能

- 分析整个资源库、当前选中的文件夹或当前选中的项目。
- 从实际项目的 `tags` 字段统计标签，不把没有任何项目使用的标签算进关系图。
- 识别 Eagle 标签群组，并支持按标签群组过滤。
- 节点大小表示标签出现次数，连线表示两个标签在同一项目中出现的次数。
- 鼠标悬停时高亮当前标签、关联标签和关联线。
- 鼠标拖动平移画布，滚轮放大缩小，支持重置视图。
- 标签节点使用可自适应宽度的贴纸式徽章显示；拖动单个标签只改变它自己的位置，关系线会实时跟随。
- 默认只显示主要关联线，避免图形被弱关系淹没；悬停或选中标签时会展开该标签全部真实关联线。可逐步显示更多标签、轮换展示其他标签，或一键恢复自动布局。
- 缩放锚点跟随鼠标当前位置，连续滚轮操作不会因缓动产生漂移。
- 标签选择和拖动只更新必要的节点、连线和筛选条件，避免每次操作重建整张图。
- Eagle 智能收藏夹的标签筛选使用数组标签的 `union` 规则实现“包含该标签”，并按 Eagle 要求传入字符串数组；后续多个标签会按 AND 条件组合。
- 更新智能收藏夹后会重新取得并打开最新对象，尽量让 Eagle 主列表立即显示新结果。
- 对图形动画、连线索引和高亮查询做了性能优化，减少标签较多时的窗口卡顿。
- 点击标签后，右侧只显示对应项目的标题和 tags，不再显示仿网页下载器的项目卡片。
- 点击标签会创建并维护一个插件专用的 Eagle 智能收藏夹“标签分析 · 当前筛选”，并修改它的标签条件；不会修改用户已有智能收藏夹。若当前 Eagle 版本暴露智能收藏夹打开接口，插件会自动跳转过去；否则会明确提示在 Eagle 侧栏打开它。
- 使用 Eagle 资源库修改时间做索引缓存判断，库有变化时手动点击“刷新库缓存”。
- 提供“标签管理”：可将一个或多个源标签合并为目标标签，例如一次将 `pv, Pv, pｖ` 合并为 `PV`；点击下方标签只会累积到待合并列表，目标标签需手动填写，输入源标签时会显示联想项，合并前确认也可关闭。
- 合并使用 Eagle 官方 `eagle.tag.merge` API，会同步更新所有项目、标签群组、常用标签和历史标签；操作不可撤销，插件会在执行前要求确认。
- 除用户明确确认的标签合并，以及点击标签时维护插件专用智能收藏夹外，不修改项目、标签组或普通文件夹。

## 安装开发版

1. 打开 Eagle。
2. 点击工具栏“插件”。
3. 进入“开发者选项”并选择“导入插件”或“打开插件目录”。
4. 选择本目录：`eagle_plugin_tag_graph`。
5. 在插件菜单中打开“标签分析”。

如果 Eagle 版本不支持直接导入开发目录，可以在 Eagle 的“开发者选项”中先创建一个“窗口”插件，再用本目录文件替换创建出来的文件。

## 设计说明

插件优先使用 `eagle.item.get({ fields })` 获取必要字段，避免读取本地 `.library` 文件，也不会依赖下载器的数据库或用户 Cookie。缓存只保存在 Eagle 插件自己的 `localStorage` 中，因此不会把个人路径、登录信息或下载记录打包进插件。

当前版本是只读 MVP。后续可以继续增加：

- 点击节点后显示项目预览面板。
- 导出 PNG/SVG/CSV。
- 时间范围和文件类型统计。
- 对 BiliDownloader 标签组提供更细的 BV、收藏夹和下载状态分析。

## 调试

`manifest.json` 当前关闭 `devTools`。开发时可以临时改成 `true`，在 Eagle 插件窗口中打开开发者工具查看控制台。
