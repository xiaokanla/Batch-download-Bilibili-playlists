## 本次更新

- 账号投稿改为独立工作流，账号搜索、候选选择和投稿获取不再与收藏夹操作混在一起。
- 候选账号使用头像卡片展示名称、粉丝数和 UID，当前选择与已载入来源更加直观。
- 主界面新增轻量动效，并优化视频卡片选中响应。
- 新增 Ctrl+A、Ctrl+F、方向键、Space、Enter、Esc 等常用键盘操作。

## 问题修复

- 修复账号搜索遇到空响应或非 JSON 风控页时显示 `Expecting value` 的问题。
- 实时账号搜索失败且存在旧缓存时自动降级使用缓存，不进行激进重试。
- 修复选择视频时触发全列表统计和重绘导致的明显延迟。

## 升级说明

- 可直接解压覆盖程序文件，原有数据目录、下载记录和 Eagle 配置无需迁移。
- 如果浏览器仍显示旧界面，请关闭旧程序后重新运行 `BiliDownloaderStudio.exe`。
- B站请求仍采用低频、缓存优先和遇到风控立即停止的保守策略。
