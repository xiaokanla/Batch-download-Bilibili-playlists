## 本次更新

- 新增缓存管理面板，可查看数据库、标签、Eagle 缓存、日志等实际位置和占用，并支持直接打开目录。
- 支持校验迁移程序数据或 Eagle 生成缓存；默认保留旧目录，选择清理时会完整校验后再删除旧缓存。
- 新增无损切换 B站账号、2K/4K 优先批量下载，以及登录前的独立引导界面。
- 在不增加 B站接口请求频率的前提下优化直链下载，可受控并行下载音视频流、使用备用 CDN，并在 Aria2 不兼容时自动回退。

## 问题修复

- 修复部分设备上 Aria2 下载失败后无法自动继续的问题。
- 迁移期间会暂停数据库写入并阻止同步、下载、标签与 Eagle 任务，避免缓存损坏；迁移失败会恢复原路径。

## 升级说明

- 可直接覆盖升级，不需要手动迁移旧数据。
- 缓存迁移入口位于右侧“缓存管理”；下载好的视频不属于缓存，不会随缓存迁移。
- 默认保留旧缓存作为备份，确认新位置工作正常后再考虑启用清理选项。
